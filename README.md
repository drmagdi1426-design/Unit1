# منصة الاختبارات التفاعلية (Gamified HR Testing Platform)

منصة اختبارات تدريبية باللغة العربية بالكامل (RTL)، مبنية على Next.js 16 + PostgreSQL،
تعرض الأسئلة والخيارات، ثم تكشف فوراً عن الإجابة الصحيحة مع تبريرها، وتُحفِّز
المتدرب بنقاط ومستويات وشارات، مع لوحة تحكم إدارية محمية بكلمة مرور توفّر
تحليلات أداء تفصيلية — بما فيها مقارنة الزمن الفعلي بالزمن المقدَّر لكل سؤال
كما هو محدَّد في ملف Excel المصدر.

## المكدّس التقني (Tech stack)

- **Next.js 16** (App Router, Server Actions, Route Handlers)
- **PostgreSQL** عبر **Prisma 7** (driver adapter `@prisma/adapter-pg`) — يعمل محلياً
  أو مع أي مزوّد Postgres سحابي (Supabase، Neon، RDS، إلخ)
- **Tailwind CSS v4** مع نظام تصميم عربي RTL (خط Tajawal)
- جلسات JWT موقّعة (`jose`) عبر ملفات تعريف ارتباط httpOnly منفصلة للمسؤول والمتدرب
- استيراد ملفات Excel عبر `exceljs`، بتنسيق صارم مطابق لملف "Item Bank" الأصلي

## البدء السريع (تطوير محلي)

### 1. المتطلبات

- Node.js 20+
- قاعدة بيانات PostgreSQL (محلية أو سحابية)

### 2. التثبيت

```bash
npm install
cp .env.example .env
# عدّل .env: ضع DATABASE_URL الخاص بك، وSESSION_SECRET عشوائياً طويلاً،
# وبيانات حساب المسؤول (ADMIN_USERNAME / ADMIN_PASSWORD)
```

### 3. تهيئة قاعدة البيانات وزرعها بالبيانات

```bash
npm run db:migrate    # ينشئ الجداول
npm run db:seed       # ينشئ حساب المسؤول، كتالوج الشارات، ويستورد بنك أسئلة
                       # الوحدة 1 من data/samples/unit1-item-bank.xlsx
```

### 4. التشغيل

```bash
npm run dev
```

افتح http://localhost:3000 — الصفحة الرئيسية للمتدربين، و
http://localhost:3000/admin/login لدخول المسؤول.

## تنسيق ملف Excel لبنك الأسئلة

يجب أن يحتوي الملف على ورقة باسم **"Item Bank"** بالأعمدة الـ26 التالية بالترتيب
(A→Z): رقم السؤال، اللغة، المسار المعرفي، المرجع الإطاري، مستوى بلوم، الصعوبة،
معامل الصعوبة المستهدف (p)، معامل التمييز المستهدف، الزمن المقدَّر (ثانية)، نص
السؤال، الخيار A-D، الإجابة الصحيحة، تبرير الإجابة الصحيحة، تصنيف/تبرير مشتت
A-D، المرجع المصدري، ملاحظات المراجع. ورقتا **"Blueprint"** و**"QA Log"**
اختياريتان وتُحفَظان كما هما لعرضهما في لوحة التحكم فقط.

يمكن للمسؤول رفع بنوك أسئلة إضافية (لوحدات أخرى) من صفحة **بنوك الأسئلة**؛ أي
عدم مطابقة للتنسيق يُرفض مع قائمة تفصيلية بالأخطاء بدلاً من استيراد جزئي.

## النقاط والمستويات والشارات

- **النقاط**: كل سؤال له قيمة نقاط مبنية على الصعوبة × وزن مستوى بلوم (يُحتسب
  عند الاستيراد ويُخزَّن على السؤال) — يُكافأ التحليل والتقييم أكثر من الحفظ.
- **المستويات**: 5 مستويات تصاعدية حسب النسبة المئوية النهائية للمحاولة.
- **الشارات**: إتمام الاختبار، دقة عالية (90%+)، تميّز كامل (100%)، تحليل عميق
  (إجابة صحيحة على كل أسئلة بلوم 4/5)، ووتيرة مثالية (دقة 80%+ مع زمن قريب من
  المقدَّر). المنطق في `src/lib/gamification.ts`.

## الخصوصية

لوحة المتصدرين علنية وتُظهر الاسم الأول + الحرف الأول من اسم العائلة فقط
(`src/app/leaderboard/page.tsx`). لوحة تحكم المسؤول وحدها تعرض الهوية الكاملة
وسجل الإجابات التفصيلي لكل مشارك.

## الاختبار الشامل (E2E smoke test)

```bash
npm run build && npm run start &
ADMIN_USERNAME=admin ADMIN_PASSWORD=... npm run test:e2e
```

يسجّل متدرباً وهمياً، يجيب عن كل الأسئلة، يتحقق من صفحة النتائج ولوحة
المتصدرين، ثم يسجّل دخول المسؤول ويتحقق من كل صفحات لوحة التحكم وتصدير CSV.
يتطلب Playwright + متصفح Chromium (مثبتان مسبقاً في بيئات معينة عبر
`PLAYWRIGHT_BROWSERS_PATH`؛ وإلا شغّل `npx playwright install chromium`).

## النشر (Deployment)

### الخيار الموصى به: Vercel + Supabase/Neon Postgres

1. أنشئ مشروع Postgres مجاني على [Supabase](https://supabase.com) أو
   [Neon](https://neon.tech).
2. انسخ سلسلة الاتصال (لـ Vercel استخدم رابط الـ **pooled connection**، عادة
   على المنفذ 6543 مع `?pgbouncer=true` في Supabase).
3. على Vercel: استورد المستودع، وأضف متغيرات البيئة التالية في إعدادات
   المشروع (Project Settings → Environment Variables):
   - `DATABASE_URL`
   - `SESSION_SECRET` (قيمة عشوائية طويلة، مثال: `openssl rand -base64 32`)
   - `ADMIN_USERNAME`, `ADMIN_PASSWORD`
4. قبل أول نشر (أو من جهازك محلياً بنفس `DATABASE_URL`)، شغّل:
   ```bash
   npm run db:deploy   # يطبّق ملفات الهجرة (migrations) على القاعدة السحابية
   npm run db:seed     # يزرع حساب المسؤول والشارات وبنك أسئلة الوحدة 1
   ```
5. انشر (Vercel يبني تلقائياً عبر `npm run build`، والذي يشغّل
   `prisma generate` قبل `next build`).

### بدائل أخرى

يعمل التطبيق على أي مضيف Node.js عادي (Railway، Render، خادم خاص، Docker) طالما
تتوفر `DATABASE_URL` صالحة وقت التشغيل والبناء. لا حاجة لتخزين ملفات محلي —
كل البيانات في PostgreSQL.

## أمان الجلسات

- جلسة المسؤول: JWT في كوكي httpOnly منفصل (`admin_session`)، صلاحيته 8
  ساعات، محمي عبر `src/proxy.ts` لكل مسار تحت `/admin` عدا `/admin/login`.
- جلسة المتدرب: كوكي httpOnly آخر (`participant_session`)، صلاحيته 6 ساعات،
  بلا كلمة مرور (تسجيل مبسّط بالاسم + البريد/الرقم الوظيفي)، ومطلوبة للوصول
  لأي مسار تحت `/exam`.
- الأسئلة تُرسَل للمتصفح **بلا** حقول الإجابة الصحيحة/التبرير/تصنيف المشتتات
  قبل الإجابة عليها (`src/lib/examService.ts` → `SafeQuestion`) — تُكشَف فقط
  بعد إرسال الإجابة عبر server action محمية بالتحقق من ملكية المحاولة.
